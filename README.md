## 🗂️ Структура заданий

### Устная часть (10 баллов)
1. **Диалог** — 6 вопросов — 1 балл
2. **Монолог** (по фотографии) — 8+ предложений — 2 балла
3. **Чтение вслух** — 3 балла

- **Задание 12** — Деепричастный оборот (1 балл)
- **Задание 13** — Сочинение 90+ слов (4 балла)
